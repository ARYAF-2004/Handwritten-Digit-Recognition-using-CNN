# Handwritten-Digit-Recognition-using-CNN
مشروع ذكاء اصطناعي يهدف إلى بناء نموذج تعلم عميق قادر على التعرف على الأرقام المكتوبة يدويًا باستخدام الشبكات العصبية الالتفافية (CNN). تم تدريب النموذج باستخدام مجموعة بيانات MNIST التي تحتوي على صور للأرقام من 0 إلى 9، بهدف تصنيف الصور وتحقيق دقة عالية في التعرف على الأنماط البصرية.
